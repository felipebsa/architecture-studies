# Architecture Studies

[Português](README.pt-BR.md)

I have already seen a lot of architecture directly in my own projects, but I learned it along the way, without really studying the theory. To be better prepared for future projects, I wanted to study it in more depth and understand why each decision is made, instead of just copying structures.

This repository is where I keep my notes from that.

## How it's organized

Each topic has its own numbered folder inside `notes/`, in the order I studied it. Every folder has the same note in two languages: `.en.md` for English and `.pt-BR.md` for Portuguese.

The `examples/` folder is for code examples of what I'm studying.

## How I study

I watch or read something about the topic, write the notes in my own words, and then review them to fix what I got wrong. When I can, I connect the topic to my own projects, like [LocTis](https://github.com/felipebsa/LocTis) and [Nippon-System](https://github.com/felipebsa/Nippon-System).
